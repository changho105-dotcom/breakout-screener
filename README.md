# 돌파매매 스크리너 (1단계 MVP)

코스피/코스닥 + 미국주식(S&P500)을 대상으로 돌파매매 체크리스트를 자동 채점하는 스크리너.

## 체크리스트 → 지표 매핑 (lib/indicators.js)
1. 시장 상승추세 → 지수 20일/60일선 기준 국면 분류 (STRONG_UP/WEAK_UP/PULLBACK/DOWN)
2. 상대강도(RS) → 60일 수익률 기준 종목-지수 비교
3. 거래량 급증 → 당일 거래량 / 20일 평균거래량 ≥ 1.5배
4. 돌파 → 20일 최고가(당일 제외) 돌파 여부, 손절선은 돌파선의 97%
5. 유동성 → 20일 평균 거래대금 기준 필터 (국내 5억원 / 미국 $5M)

체크리스트 통과 개수가 0~5점으로 점수화되어 정렬됩니다.

## ⚠️ 배포 전 꼭 확인해야 할 것 (샌드박스에서 검증 불가능했던 부분)

개발 환경(샌드박스)에서 `finance.naver.com`과 `stooq.com` 접속이 네트워크 정책상
막혀 있어서, 아래 두 가지는 **실제로 살아있는 응답을 받아본 적이 없습니다.**
로직 자체(지표 계산)는 가짜 데이터로 단위 테스트를 거쳤지만, 크롤링 파싱 부분은
Railway에 올린 뒤 직접 호출해서 확인해주세요.

- `lib/krSource.js` — 네이버 금융 HTML 테이블 구조(`table.type_2`, `a.tltle`)가
  바뀌었다면 `fetchStockList`가 빈 배열을 반환합니다.
- `lib/usSource.js` — stooq.com의 CSV 응답 형식이나 심볼 규칙(`.us` 접미사,
  지수 심볼 `^spx`)이 다르면 `fetchOHLCV`/`fetchIndexOHLCV`가 빈 배열을 반환합니다.

둘 다 빈 배열이 오는 형태로 "조용히" 실패하니, 배포 후 아래로 직접 호출해서
`stocks` 배열이 비어있지 않은지 꼭 확인하세요:

```
GET /api/screen/kr
GET /api/screen/us
```

## 미구현 (다음 단계에서 추가)
- 국내(코스피/코스닥) 종목의 업종(섹터) 정보 — 미국은 GICS 섹터로 구현됨
- 국면별 정밀한 베이스 하단가 계산 (현재는 돌파선의 97%로 단순화)
- 백테스터 (2단계) — 여기서 구현한 lib/indicators.js를 그대로 재사용할 예정

## 실행
```
npm install
npm start
```
`http://localhost:3000` 에서 대시보드 확인.

## Railway 배포
1. 이 폴더를 GitHub 저장소로 push
2. Railway에서 새 프로젝트 → GitHub repo 연결
3. 별도 환경변수 없음 (지금 단계는 API 키 불필요 - 크롤링 기반)
4. 배포 후 `/api/screen/kr`, `/api/screen/us` 호출해서 정상 동작 확인
