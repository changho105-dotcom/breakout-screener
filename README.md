# 돌파매매 스크리너 (1단계 MVP)

코스피/코스닥 + 미국주식(S&P500)을 대상으로 돌파매매 체크리스트를 자동 채점하는 스크리너.

## 체크리스트 → 지표 매핑 (lib/indicators.js)
1. 시장 상승추세 → 지수 20일/60일선 기준 국면 분류 (STRONG_UP/WEAK_UP/PULLBACK/DOWN)
2. 36주 신고가 근접 → 36주(180거래일) 최고가 대비 -20% 이내인지 (예전 RS 자리를 대체)
3. 거래량 급증 → 당일 거래량 / 20일 평균거래량 ≥ 1.5배
4. 36주 전고점 돌파 → 36주 최고가(당일 제외) 돌파 여부, 손절선은 돌파선의 97%
5. 유동성 → 20일 평균 거래대금 기준 필터 (국내 5억원 / 미국 $5M)

체크리스트 통과 개수가 0~5점으로 점수화되어 정렬됩니다.

⚠️ 20일 박스권 돌파 → 36주 전고점 돌파로 기준을 바꾸면서 신호 발생 빈도가 크게 줄어듭니다.
36주 신고가 돌파는 원래 훨씬 드문 이벤트라, 스크리너에 뜨는 종목 수 자체가 적어지는 게 정상입니다.

## 신고가/돌파 기준 기간 선택
화면 상단 드롭다운에서 60일 / 120일 / 36주 / 52주 중 선택 가능합니다 (스크리너·백테스트 공통 적용).
바꾸면 해당 기간 기준으로 즉시 다시 계산됩니다. 옵션 추가/조정은 `lib/indicators.js`의 `LOOKBACK_OPTIONS`에서.

## ⚠️ 배포 전 꼭 확인해야 할 것 (샌드박스에서 검증 불가능했던 부분)

개발 환경(샌드박스)에서 `finance.naver.com`과 `stooq.com` 접속이 네트워크 정책상
막혀 있어서, 아래 두 가지는 **실제로 살아있는 응답을 받아본 적이 없습니다.**
로직 자체(지표 계산)는 가짜 데이터로 단위 테스트를 거쳤지만, 크롤링 파싱 부분은
Railway에 올린 뒤 직접 호출해서 확인해주세요.

- `lib/krSource.js` — 네이버 금융 HTML 테이블 구조(`table.type_2`, `a.tltle`)가
  바뀌었다면 `fetchStockList`가 빈 배열을 반환합니다.
- `lib/usSource.js` — stooq.com의 CSV 응답 형식이나 심볼 규칙(`.us` 접미사,
  지수 심볼 `^spx`)이 다르면 `fetchOHLCV`/`fetchIndexOHLCV`가 빈 배열을 반환합니다.

둘 다 빈 배열이 오는 형태로 "조용히" 실패하니, 배포 후 아래로 직접 호출해서
`stocks` 배열이 비어있지 않은지 꼭 확인하세요:

```
GET /api/screen/kr
GET /api/screen/us
```

## 미국장 관련 참고
- 종목 유니버스를 S&P500 단독에서 **다우30 + 나스닥100 + S&P500** 통합(중복 제거)으로 확장
  (다우30/나스닥100 리스트: yfiua.github.io/index-constituents, S&P500+섹터: datasets/s-and-p-500-companies)
- 지수는 S&P500(^GSPC)/다우(^DJI)/나스닥종합(^IXIC) 3개를 각각 계산해서 화면에 게이지로 표시
- 다만 개별 종목의 RS·포지션비중 계산 기준 지수는 **S&P500 하나로 통일**했습니다(다우·나스닥은 참고용 게이지). 종목마다 소속 지수 기준으로 따로 계산하려면 추가 작업이 필요해서 지금은 단순화한 상태 - 필요하시면 다음 단계에서 분리 가능
- OHLCV 소스를 stooq.com에서 Yahoo Finance Chart API로 교체함
  (stooq가 Railway 같은 클라우드 IP를 차단하는 것으로 보여서 교체)
- 요청량을 줄이기 위해 MVP는 최종 250개 종목까지만 스캔합니다 (다우30·나스닥100은 항상 포함, 나머지는 S&P500으로 채움)
  (환경변수 `US_UNIVERSE_LIMIT`로 조정 가능, Railway → Variables에서 설정)
- Yahoo Finance나 yfiua 데이터셋도 언젠가 막히거나 형식이 바뀔 수 있음 - 이 경우
  `/api/screen/us` 에러 메시지에 원인이 그대로 표시됩니다

## 백테스터 (2단계)
스크리너와 동일한 `lib/indicators.js` 로직을 과거 데이터에 그대로 적용해서 검증합니다.
- 화면의 "백테스트" 탭에서 미국 주식 티커 입력 후 실행 (예: PLTR)
- API: `GET /api/backtest/us/:ticker`
- 진입: 조건 충족 다음날 시가 / 청산: 손절선 터치, 국면 하락 전환, 또는 최대 90거래일 보유 초과
- 매 거래마다 자본 전액을 순차 재투자한다고 가정한 단순 모델입니다 (분할매수/포지션 사이징은 3단계 봇에서 반영 예정)

## 미구현 (다음 단계에서 추가)
- 국내(코스피/코스닥) 종목의 업종(섹터) 정보 — 미국은 GICS 섹터로 구현됨
- 국면별 정밀한 베이스 하단가 계산 (현재는 돌파선의 97%로 단순화)
- 백테스터 (2단계) — 여기서 구현한 lib/indicators.js를 그대로 재사용할 예정

## 실행
```
npm install
npm start
```
`http://localhost:3000` 에서 대시보드 확인.
